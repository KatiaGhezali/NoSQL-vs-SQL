# MongoDB vs SQL

A simple web-based presentation comparing MongoDB, a NoSQL database, with SQL relational databases.

## Features

- 5 slide presentation
- Comparison of MongoDB and SQL
- Covers data models, schemas, scaling, queries, and transactions
- Previous and Next navigation buttons
- Keyboard navigation using the left and right arrow keys

## Files

- `index.html` Presentation structure and content
- `style.css` Presentation styling
- `script.js` Slide navigation functionality

## How to Run

Open `index.html` in your web browser.

Use the **Previous** and **Next** buttons or the **left and right arrow keys** to navigate through the slides.
